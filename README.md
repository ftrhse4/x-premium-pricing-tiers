## 8 美元这一档是分水岭

Basic 是纯粹的“功能档”：编辑帖子（发布后 1 小时内可做有限修改，只限原帖和引用帖，回复不行）、最长 25000 字的长文、约 3 小时 / 8GB 的长视频上传（1080p，仅限网页端和 iOS）、文本格式、书签文件夹、自定义应用图标、创建 Community，外加最低一档的回复优先加权。

但它有两个“没有”：没有蓝色认证标，也不减少广告。官方 FAQ 写得很直白，Basic 不提供减少广告的体验。如果你冲着“少看广告”或“蓝标”去，这 3 美元会花得不明不白。

## 开通之前，这几件事先知道

- 所有订阅者都必须绑定并确认手机号。一个手机号已经绑了超过 10 个账号、绑在 30 天内注销的账号上、或绑在被封禁的账号上，都无法通过验证。
- 蓝标不是付款立刻到账。新订阅需要经过资格审核，通常要几个工作日；账号需要有显示名称、头像和已确认的手机号。
- 付款后改头像、改昵称、改 @handle，蓝标会暂时消失，直到重新审核通过，审核期间不能再改资料。打算在发布日换新品牌形象的运营，别把改资料和发布排在同一天。
- 退款规则偏紧：订阅原则上不退款（法律强制要求的除外），账号被封的情况也不退。降级不退差价，当前计费周期结束后才切到新档位；网页端升级时，剩余额度会抵扣新档位费用，补差价立即生效。
- 不想续费，至少在自动续费前 24 小时取消。取消后权益保留到本期结束，已付的钱不退。

## 常见问题

**Basic 有蓝色认证标吗？**
没有。蓝标只提供给 Premium 和 Premium+ 订阅者，且需要通过资格审核。

**Basic 能减少广告吗？**
不能。官方 FAQ 明确 Basic 不包含减少广告的体验；广告约减半从 8 美元的 Premium 档开始，全站基本无广告只有 Premium+。

**为什么手机应用里更贵？**
苹果和谷歌对应用内订阅抽成，X 把成本转嫁到了应用内价格上。同一个套餐在网页端开通更便宜。

**中途降级会退钱吗？**
不会。降级后当前套餐保留到本计费周期结束，再切换到新档位，旧周期不退差价（法律另有要求的除外）。

**取消订阅后蓝标还在吗？**
会保留到你已付费的订阅期结束，除非账号被封或蓝标因其他原因被 X 移除。

**X 官方有优惠码吗？**
